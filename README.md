# keiba-yoso — トラックバイアス予想ツール

その日・その競馬場のレース結果（枠番・コーナー通過順位）を取り込み、内枠/外枠や逃げ・先行・差し・追込のどちらが有利かを自動集計して表示する、単一HTMLのブラウザ用ツールです。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要）。データは端末のブラウザ内（localStorage）に保存されます。

1. 開催場と日付を選択
2.「＋ レース結果を追加」から、確定したレースの結果を取り込みます
   - **URL取得**: netkeiba等の結果ページURLを入力し自動取得を試みます（CORSプロキシ経由のため失敗する場合があります）
   - **HTML貼り付け**: 結果ページの「ページのソースを表示」→ 全選択コピーしたものを貼り付けて解析します（最も確実）
   - **手入力**: 枠番・着順・通過順位を直接入力します
3. 抽出内容を確認・修正して保存
4. レースが増えるほど「本日のバイアス」の精度が上がります（3レース以上を推奨）

「履歴」タブから、過去に保存した開催日のデータを見返せます。
